# ECS O2 Flux Visualization

ECS and Hammerhead Project READ ME File:

The data collected for this project was collected in August 2026 in South Bay, Virginia just inshore of Wreck Island using eddy covariance and Hammerhead systems. Sites were South Bay 3 _____ (Seagrass meadow) and _____ (Bare sand). ECS #1 and the Hammerhead were placed at South Bay 3, while ECS #2 was placed at the bare sand site. Data within this project contains data from FireSting O2 sensors, Nortek Acoustic Doppler Velocimeter (ADV), and internal sensors of pressure, temperature, etc. The goal of this project is to visualize this mass of raw data collected over 3 days containing millions of datapoints. I want to make a figure similar to Long et al., 2015 (Figure 2), showing directional velocities (cm/s), O2 Concentration (umol/L), cumulative flux (mmol/m^2), and the average flux (mmol m^-2 d^-1) over the 72 hours the instruments were deployed for. In addition, I also would like to make a Geographical figure mapping the study sites and the meadow extent identified by the closest date that could be mapped using remote sensing.

This folder contains a CODE, DATA folders, and a README.md file.
	- DATA folder holds the raw data files for the ECS system
	- CODE folder contains a notebook for EDA of the raw data files
	- README.md (This file) contains descriptive information 

This folder has been added as a separate repository on GitHub.

Additional files/folders such as figures, adjusted data files, etc. will be added as needed.

Many of these figures will be modeled after those found in Berger et al., 2020 (https://doi.org/10.1002/lno.11397) & Long et al., 2015 (https://doi.org/10.3354/meps11314).
